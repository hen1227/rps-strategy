# Security

If you find a security problem in RPS Strategy, please report it privately
rather than in a public issue: email **support@henhen1227.com** with "Security"
in the subject.

Say what an attacker could do, and how to reproduce it. I'll reply as soon as I
can, fix it as quickly as I can, and credit you in the fix if you'd like.

This covers the code in this repository and the service it runs at
rps.henhen1227.com and api-rps.henhen1227.com. Please don't test against real
players' accounts or degrade the live site. A local server (see
[README.md](README.md#run-locally)) reproduces nearly everything.

The engine, [RPSFish](https://github.com/hen1227/rpsfish), is a separate
repository.
