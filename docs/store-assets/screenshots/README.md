# Store screenshots

Captured on 2026-09-29 from the iOS simulators (iPhone 17 Pro Max, iPad Pro
13-inch M5) running the working tree as it stood that day. Every name,
rating, count and chat line is invented. The boards and move lists come from
real RPSFish games played for the purpose.

| Folder | Size | Where it goes |
| --- | --- | --- |
| `app-store/iphone-6.9/` | 1320×2868 | App Store Connect, 6.9" iPhone display |
| `app-store/ipad-13/` | 2064×2752 | App Store Connect, 13" iPad display (needed while `supportsTablet` is `true`) |
| `google-play/phone/` | 1440×2560 | Play Console, phone screenshots |
| `google-play/tablet/` | 1800×3200 | Play Console, 7-inch and 10-inch tablet screenshots |
| `uncaptioned/` | Apple's sizes | The same captures with no frame or caption, if plain screenshots are preferred for Apple |

Upload them in file order:

1. **Live match** (Total War): *Rock, paper, scissors, with a board and a clock.*
2. **Spectating a corner race** (Intransitive): *Race for the corner their army started in.*
3. **Analysis board** (Intransitive): *A real engine, running on your phone.* The iPad set says *iPad*. The Play sets say *showing its best lines*, from when RPSFish ran natively only on iOS; it runs on Android too now, so the iPhone caption fits them as well.
4. **Game review** (Infiltration): *Every move graded. Both accuracies.*
5. **Lobby**: *Ranked matches, bots, tournaments, and whoever is next to you.*
6. **Practice bots**: *Six practice bots, from Pebble to Obsidian.*
7. **Appearance**, shown in Midnight with the Walnut board and Drawn pieces: *Make the board your own.*

The Play images crop out the iOS status bar. Captions are set in Arial Rounded
MT Bold, in `#0C6434` on `#FEEDB8` to match the feature graphic.
