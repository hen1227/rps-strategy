# The words this server will not carry.
#
# Read by filter.go, which explains what the two sections mean and why the
# distinction matters. The short version:
#
#   [anywhere]  refused wherever it appears, even inside another word. Only for
#               terms long and unambiguous enough that no ordinary word
#               contains them — five letters minimum, enforced at load.
#   [word]      refused only as a whole word. This is where anything short or
#               ambiguous goes: "ass" here refuses "ass" and leaves "class",
#               "assess", and "Bass" alone.
#   [name]      refused anywhere inside a *username*, and nowhere else. A name
#               has no spaces in it, so whole-word matching does almost nothing
#               there: "fuckyou" is one word. This section is the answer, and it
#               is a hand-picked subset rather than the [word] list reused —
#               substring-matching that would refuse Dickson, Pakistani,
#               raccoon, Mustard, and suspicious.
#
# Matching folds case, strips spacing and punctuation, and undoes the usual
# digit substitutions, so a term listed once covers "F.U.C.K", "f u c k", and
# "fu(k". Stretched spellings are handled too. None of that needs listing here:
# write the plain word and the matcher does the rest.
#
# Adding a term is editing this file. Think about which section it belongs in —
# a short or ambiguous term in [anywhere] is how a filter starts refusing
# innocent messages and teaching people that it is broken. "chink" is the
# example to keep in mind: a real slur, and also the word in "a chink in his
# armour", which is a sentence somebody will type on a strategy site. It is in
# [word] for that reason and the trade is deliberate.
#
# This list is deliberately narrow. It covers slurs and the strongest
# profanity, and nothing else. Insults, heat, and rudeness are for the report
# button and the host, not for a word list that cannot tell an argument from
# abuse — and neither are proper nouns: "nazi" and "hitler" are absent because
# refusing them refuses the sentence condemning them just as readily.
